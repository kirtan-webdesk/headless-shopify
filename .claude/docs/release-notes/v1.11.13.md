## The semantic-drift incident (this is the important part)

The Shopify window said: "the canonical taxonomy is `_spine/designer-agent/knowledge/02-design-path-decision.md`: 1 = theme-driven, 2 = pattern-driven, 3 = component-custom, 4 = brand-defining custom, 5 = multi-store, 6 = headless."

**That's not what the spine says.** The actual spine taxonomy has been:

| # | Actual spine label |
|---|--------------------|
| 1 | Custom-over-default-theme |
| 2 | Inspired-by-predefined-template |
| 3 | Fully custom from scratch |
| 4 | Headless |
| 5 | Figma import |
| 6 | Page builder driven |

Path 1 is roughly the same in spirit. Every other slot is different. The Shopify window's fix aligned arm content to a taxonomy that doesn't exist in the spine. Their fold would have introduced *new* drift while claiming to fix drift.

**How this happened:** Shopify new-build was authored back in v1.6.0 with local labels ("pattern-driven," "component-custom," "brand-defining custom"). Those labels are more of a customization-depth ladder — arguably a clearer model than the spine's mixed input-source-and-mechanism taxonomy. The Shopify window read those local labels and assumed they were the spine's, then "fixed" other files to match. Nobody had gone back to the actual spine file since v1.5.4.

**How I chose to resolve it:** you picked "realign arm content to actual spine" over "update spine to Shopify's taxonomy." Reasoning I agreed with: the spine has been the reference for 6 months across multiple arms; rewriting the spine would cascade into every arm file that already cites it correctly. Realigning the drifted arm content is smaller scope, and Shopify's proposed labels can be revived later if we decide the depth-ladder framing is genuinely better (would be a v1.12.0-scope taxonomy migration).

**How the class-of-bug gets prevented going forward:** the spine file now includes an explicit "cite, don't restate" convention. If an arm file needs a concept the spine lacks, that's a spine-change escalation, not a local invention. The Shopify window was right that no text scanner catches this — it's structural, not textual. The convention lives at the source of truth, where the next writer will see it before writing.
