### E7 — Spine contamination scan extended into verify-edition-integrity.sh

`verify-edition-integrity.sh` new function: `scan_spine_contamination()`.

Rule: grep `_spine/*` files for file-path references (`<arm>/knowledge/`, `<arm>/projects/`, `<arm>/templates/`) to non-installed platform arms. Any match → FAIL.

Contamination rules per edition (v1.11.6):
- **Shopify edition:** flags refs to `wordpress-woocommerce/`, `bigcommerce/`, `magento-adobe-commerce/`
- **WordPress edition:** flags refs to `shopify/`, `bigcommerce/`, `magento-adobe-commerce/`

- **Magento edition:** flags refs to `shopify/`, `wordpress-woocommerce/`, `bigcommerce/`
- **Full edition:** SKIP (canonical spine allowed to enumerate)

This is a narrow scan (file paths only) — doesn't flag universal enumeration (platform names in routing tables, valid-value lists, cross-platform detection knowledge). The scan targets ONLY the strong signal: file paths that would fail if the LLM tried to Read them.

## Master retrospective — 2 stub regressions in 3 patches

Pattern I need to own:

- v1.11.3: gutted Shopify README → 4-line stub. Fixed in v1.11.4.
- v1.11.5: same thing again. Fixed in v1.11.6.

Root cause: my patch-release packaging script used inline `cat > README.md <<EOF` with placeholder content. Each patch release, I "quickly stubbed" the edition READMEs and forgot to fill them in with the previous version's content.

Fix landed in v1.11.6:
1. `tools/edition-readmes/` registry — version-controlled README templates per edition
2. Packaging script pulls from registry (no inline stub possible)
3. Integrity check flags README < 5 lines as FAIL
4. ship-bundle.sh gate refuses to ship on FAIL

Three defensive layers now. Recurrence should be structurally impossible.

Ownership discipline note added to my personal packaging checklist:
- Never use inline `cat > README.md <<EOF` in packaging
- Always run `ship-bundle.sh` for each zip (not just spot-check)
- If a new edition is added, its README template goes in `tools/edition-readmes/` FIRST, before touching the packaging script
