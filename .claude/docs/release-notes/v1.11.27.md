## Sales-visible finding — Node version cross-architecture trap

**Any agency doing both Shopify and BigCommerce headless needs Node 24, or per-project version management.**

- `@bigcommerce/create-catalyst` requires `^24.0.0`
- `@bigcommerce/catalyst` (the package it depends on) accepts `^20 || ^22 || ^24`
- `@shopify/cli-hydrogen` requires `^22 || ^24`

**A workstation or CI image standardised on Node 22 for Hydrogen work cannot scaffold a Catalyst project.** Not discoverable from either project in isolation — you find it when the developer types `npm create @bigcommerce/catalyst` on a machine set up for Hydrogen and gets an incompatible-engines error.

Recorded in `pointers/verified-facts.md` §13a. Belongs in D-HL-ENV-01 check 1 for architecture D. Cross-architecture consequence, not a per-arch fact.
