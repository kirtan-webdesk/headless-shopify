## Critical design choices worth flagging

1. **Vanilla WP + custom theme is the default.** Not commercial themes, not Sage, not FSE. Pragmatic for WebDesk's most common pattern.

2. **Classic editor + ACF is primary.** Block editor (Gutenberg) explicitly secondary. Many WP agencies still on this stack; the skill reflects that reality.

3. **Page builders supported (Elementor / Divi).** Per D-WP-03 — for specific use cases only, NOT entire site. Forbidden rules (PB-001 to PB-006) enforce.

4. **WooCommerce + HPOS-aware throughout.** WC-002, WC-003 specifically address HPOS migration concerns.

5. **Plugin selection rubric is mandatory.** No installing plugins without going through `14-app-plugin-ecosystem.md` evaluation.

6. **Cart + checkout require senior dev review (WC-004).** Same pattern as Shopify SEC-003.

7. **WordPress Redesign skill mirrors Shopify Redesign structure.** Familiar patterns; easier knowledge transfer.

8. **All forbidden rules apply on top of global.** `_spine/shared-knowledge/forbidden-global.md` rules apply to WordPress code too.

## Honest notes

1. **Many files in this release are dense first drafts.** Real pilot will surface patterns the docs miss. Expect K4 feedback loop iteration.

2. **WordPress is more loose than Shopify.** Conventions vary; teams have strong preferences. Docs reflect WebDesk's preferred patterns — won't match every WordPress developer's preference.

5. **Plugin compatibility audit (`plugin-compatibility-matrix.md` template) will catch most pilot risks.** Take this seriously at G0.5.
