## Spine + tools changes (master-window-owned)

### `tools/scripts/validate-frontmatter.py` — classify() bug fix

The `classify()` function only matched `/knowledge/` and `/templates/` with a leading slash. When the validator was invoked with a single skill directory as root (e.g., `validate-frontmatter.py skills/wordpress-woocommerce/`), relative paths starting with `knowledge/` (no leading slash) fell through to "ignored." Files were silently dropped from validation.

**Fix:** Added `p.startswith("knowledge/")` and `p.startswith("templates/")` conditions, mirroring the existing `docs/` handling.

**Verification:** Running validator against `skills/wordpress-woocommerce/` now reports 32 files (was 11). Repo-root invocation unchanged.

**Reported by:** WP skill-dev window escalation 2026-06-10.

### MODIFIED — `knowledge/20-elementor-architecture.md`

Two new sections added (pilot items 4, 5, 7, 8):

- **Selector discipline — element IDs are volatile.** Never write CSS selectors against generated `.elementor-element-{id}` classes. They change when the page is duplicated, exported, or the user rebuilds the section. Use custom CSS classes assigned via the widget's Advanced tab instead.
- **Programmatic content injection protocol.** When injecting content via Theme Builder Dynamic Tags or PHP filters, follow the atomic 4-step cycle: inject → regenerate CSS → hard refresh → visual verify. Skipping regeneration ships stale CSS; skipping verification hides it until QA.

Anti-patterns extended to 12 (was 10) — items 11 and 12 cover the new patterns.

**Flagged caveat:** The internal Elementor APIs `\Elementor\Core\Files\CSS\Post` and `files_manager->clear_cache()` are mentioned. These are internal APIs that may break between Elementor versions. The file notes this — verify against the pinned Elementor Pro version (per `21-elementor-performance.md` version pinning strategy).

### MODIFIED — `knowledge/22-elementor-qa-checklist.md`

Section 2 gained two new check blocks:
- **Mandatory pre-reorder CSS audit (CRITICAL severity).** Before reordering Theme Builder templates or duplicating widgets, audit existing CSS for ID-based selectors that would silently break. Tied to pilot items 7 and 8.
- **Programmatic injection verification checks.** Verify CSS regeneration + visual confirmation after every programmatic content injection.
